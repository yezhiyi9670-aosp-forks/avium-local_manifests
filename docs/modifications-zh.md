### 个人分支

- 此包有亮度补偿 HDR 支持，但和某些 ColorOS16 移植版一样存在系统界面亮度异常、切换时吃闪光弹等问题。默认设置已降低 HDR 强度缓解此问题。如果仍然影响使用，请在设置中（设置 → 显示 → HDR 亮度增强）关闭此功能。

- 有意移除了「时刻」「Via」两个预装应用，其中 Via 替换为 LineageOS Jelly。
  - 「时刻」似乎是专有软件，对用户数据只提供在线同步而没有本地导出选项，存在 lock-in 嫌疑，且对我而言开发者、备案、隐私条款等均无法考证。
  - 「Via」是专有软件，用其替代 LineageOS Jelly 不太妥当。

- 此包启用了三等级振动强度分级。除铃声、闹钟外，其余振动强度默认为中等，如果太弱可在设置中调节。

- Recovery 亮度较低是有意为之。

### 原版 LineageOS/AviumUI

- 息屏显示本身缺乏自动亮度支持（虽然可以无级调光），因此目前配置限制其最高亮度约 59nit。息屏常亮模式的完全静息状态下限制约为 39nit。

- 实验性「万象时钟」功能缺少息屏防烧屏逻辑，请避免同时开启万象时钟和息屏常亮。

- 指纹识别就绪状态下，显示亮度可能略有偏差；指纹识别激活状态下，夜间光效和极暗效果会暂时失效。

- 开启指纹解锁的情况下，息屏常量静息状态切入切出时可能出现短暂亮度闪跳。

- 系统情景模式（设置 → 系统 → 系统情景）的默认配置会覆盖三段式开关设置的响铃模式。请关闭系统情景功能或者将情景模式的「响铃模式」设为「保持不变」。

- 三段式开关（设置 → 系统 → 按键 → 更多按键 → 警报滑块）如果配置了任何与勿扰模式相关的动作（仅限优先、完全静音、仅限闹钟），则状态切换时会覆盖默认勿扰模式设置，并且会停用当前已启用的其他勿扰模式。由于我的修改，默认配置（静音、振动、正常响铃）下现在已不会触发该问题。

### 并非我们的锅

- 可能存在众所周知的微信视频通话画面比例异常、卡死问题（不确定是否存在，需要有人验证）。权宜之计是使用官网 32 位版微信。
